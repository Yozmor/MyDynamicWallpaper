<h1 align="center">MyDynamicWallpaper</h1>

Динамические обои для Windows, которые меняются вместе с солнцем. Программа знает твои координаты, каждый день сама считает время рассвета, восхода, заката и сумерек и в нужный момент ставит подходящую картинку: рассветную утром, дневную днём, закатную вечером и ночную ночью. Темы могут менять картинки и по сезонам.

Работает в фоне из трея, обои ставятся на все мониторы.

## Возможности

- Расчёт восхода, заката и сумерек по координатам и дате, с учётом часового пояса системы.
- Полярный день и полярная ночь обрабатываются отдельно: если солнце не заходит или не восходит, картинки не «залипают» на неправильном времени суток.
- Сезоны: тема может содержать несколько наборов картинок (например, зима/весна/лето/осень), программа сама выбирает набор по текущему месяцу.
- Выбор города из встроенного списка (`cities.json`) или ввод координат вручную.
- Окно с предпросмотром: можно посмотреть, какая картинка будет в каждом сезоне и в каждой части суток.
- Иконка в трее: выбрать тему, открыть интерфейс, включить автозапуск, выйти.
- Автозапуск вместе с Windows.
- **ThemeBuilderGUI**: отдельный графический конструктор тем. Собираешь свою тему из собственных картинок без ручной правки файлов.

## Установка

**1. Скачай файлы.** Открой папку [`program`](program) и скачай оттуда (кликни по файлу → кнопка **Download raw file**, стрелка вниз справа):

| Файл | Что это |
|---|---|
| `MyDynamicWallpaper.exe` | Сама программа |
| `ThemeBuilderGUI.exe` | Конструктор тем (нужен, если хочешь собрать свою тему) |
| `cities.json` | Список городов для выбора местоположения |

**2. Положи их в одну папку**, например `C:\Tools\MyDynamicWallpaper`, и создай рядом пустую папку `themes`: туда удобно складывать темы.

**3. Запусти `MyDynamicWallpaper.exe`.** При первом запуске программа спросит местоположение: выбери ближайший город или введи широту и долготу. Потом выбери тему: правый клик по иконке в трее → **Выбрать тему...**

Нужна Windows 10 или 11.

## Как пользоваться

Программа живёт в трее, возле часов. Правый клик по иконке:

- **Выбрать тему...** — открыть файл темы `.dww`;
- **Открыть интерфейс** — окно с предпросмотром, информацией о рассвете и закате и настройкой местоположения;
- **Автозапуск** — запускать вместе с Windows;
- **Выход**.

Обои проверяются каждые 5 секунд, так что смена картинки происходит почти сразу после наступления нового периода суток.

Настройки (выбранная тема, координаты, автозапуск) хранятся в `%APPDATA%\MyDynamicWallpaper\settings.json`.

## Свои темы

Тему проще всего собрать в **ThemeBuilderGUI**:

1. Создай сезоны (один или несколько).
2. В каждый сезон добавь картинки (`jpg`, `png`, `bmp`, `webp`).
3. Каждой картинке назначь роль: **Рассвет**, **Полдень**, **Закат** или **Полночь**. В каждом сезоне должны быть назначены все четыре роли.
4. Экспортируй тему в файл `.dww` и выбери его в программе.

Файл `.dww` — это архив, внутри которого лежат картинки и описание темы `theme.json`.

### Как распределяются сезоны

Год начинается с марта и делится поровну между сезонами темы. Например:
- 1 сезон — одни и те же картинки круглый год;
- 4 сезона — по 3 месяца: март–май, июнь–август, сентябрь–ноябрь, декабрь–февраль;
- 12 сезонов — отдельный набор на каждый месяц.

### Формат theme.json

```json
{
  "sunElevationDawn": -12,
  "sunElevationDusk": -12,
  "seasons": [
    {
      "name": "Лето",
      "sectors": [
        { "type": "dawn",  "image": "summer_dawn.jpg" },
        { "type": "day",   "image": "summer_day.jpg" },
        { "type": "dusk",  "image": "summer_dusk.jpg" },
        { "type": "night", "image": "summer_night.jpg" }
      ]
    }
  ]
}
```

- `sunElevationDawn` / `sunElevationDusk` — на какой высоте солнца под горизонтом (в градусах) начинается рассвет и заканчиваются сумерки. По умолчанию −12°, это навигационные сумерки.
- `seasons` — список сезонов, в каждом картинки с типами `dawn`, `day`, `dusk`, `night`.

## Сборка из исходников

Скачай весь репозиторий (зелёная кнопка **Code → Download ZIP**) и запусти `build.bat`. Он соберёт `MyDynamicWallpaper.exe` и `ThemeBuilderGUI.exe` с иконками в папку `program`. Нужен MinGW-w64 (`g++` и `windres` в PATH), например из [MSYS2](https://www.msys2.org/) или [winlibs.com](https://winlibs.com/).

Через Visual Studio можно собрать по-старому, CMake'ом:

```
cmake -B build
cmake --build build --config Release
```

| `tools/theme_builder_gui.cpp` | Конструктор тем |
| `program/` | Готовые exe и `cities.json` |
| `build.bat` | Сборка через MinGW |
| `include/nlohmann/` | Библиотека [nlohmann/json](https://github.com/nlohmann/json) для чтения JSON |
